# team-availability
Shared availability board for the Sovereigns. Everyone checks off when they're free during the week, saves it, and the Team availability tab shows a live combined view — so we can actually see when the whole team can scrim or play without a group chat back-and-forth every week.

## How to use it
# My availability — type your name, click your free time slots (or click a day name to select/clear the whole day), then hit Save.

# Team availability — shows everyone's combined schedule, color-coded by how many people are free at each time.

# Names are case-sensitive, so type yours the same way every time (e.g. always "Sam", not sometimes "sam").
